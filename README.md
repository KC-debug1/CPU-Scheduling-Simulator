# CPU Scheduling Simulator

Course: CSN4224 Operating System

Project title: Mini Operating System - CPU Scheduling Algorithm Simulator

## How to Run

1. Open `index.html` in a web browser.
2. Enter 3 to 10 processes.
3. Set arrival time, burst time, and priority for each process.
4. Keep Round Robin quantum as `3` for the assignment requirement.
5. Choose `Compare all` or select one algorithm.
6. Click `Run Simulation`.

No installation is required.

## Implemented Algorithms

- Round Robin, default quantum 3
- Preemptive SJF
- Non-Preemptive SJF
- Preemptive Priority
- Non-Preemptive Priority
- First Come First Serve

Priority rule: smaller priority number means higher priority.
